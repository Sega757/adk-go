## 2024-05-14 - Fix DoS via io.LimitReader on http.Request.Body
**Vulnerability:** The HTTP handlers in `server/agentengine/controllers/agent_engine.go` read unbounded JSON payload bodies from external requests using `io.ReadAll(io.LimitReader(req.Body, c.maxPayloadSize))`.
**Learning:** `io.LimitReader` silently stops returning bytes when the limit is reached, but it does NOT signal the underlying HTTP server to close the connection or abort the read early. A malicious client can continue to slowly stream gigabytes of data to an open socket, resulting in a Slowloris-style Resource Exhaustion / DoS attack because the connection is kept alive and the goroutine blocked.
**Prevention:** Always use `http.MaxBytesReader(w, req.Body, limit)` when reading from `http.Request.Body`. It natively hooks into the `net/http` server logic to forcefully close the connection (`Close()`) and immediately return a `http: request body too large` error (which can be mapped to a 413 response) if the limit is exceeded.
